## 範圍與方法

基準提交：`1f27188`。工作目錄開始時沒有未提交修改。

Windows / Python 3.10 / Tkinter 桌面工具；外部 BallonsTranslator 負責翻譯，工具負責章節整合、佇列、CBZ 匯出與通知。沿用 pywin32 312 與 PyInstaller 6.22.2，沒有升級依賴。

檢查呼叫與資料流：

- `Comic sorting.py`：掃描、選取、整合暫存／備份、來源清理、設定保存與關閉流程。
- `comic_core.py`：圖片對應、範圍分類、路徑與連結限制、CBZ 驗證、JSON 原子替換。
- `translation_queue.py` / `queue_worker.py`：工作快照、篩選與選取、失敗依賴、暫停／停止、子程序、背景計數、保存檢查點。
- `queue_history.py`：SQLite 參數化查詢、交易、費用合計及部分用量。
- `bt_settings.py` / `bt_run_bridge.py`：設定驗證、外部修改檢查、備份、原生指定頁面傳遞。
- `ntfy_notifications.py` / `windows_notifications.py` / `app_logging.py`：權杖保護、禁止轉址、通知失敗隔離、敏感資訊遮罩與紀錄輪替。
- README、requirements、PyInstaller spec、GitHub 驗證／發佈流程及完整 unittest 測試。

測試使用暫存漫畫與設定；未修改使用者的漫畫、佇列設定或歷史資料，未執行付費翻譯、ntfy 發送或遠端寫入。這是來源碼檢查與本機回歸測試，不代表已驗證所有外部服務或競態。
