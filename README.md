## 功能

- 從高層級漫畫目錄自動建立「系列 → 章節」樹狀列表。
- 系列依更新時間由新到舊排列，章節依最小章號由小到大排列。
- 顯示章節狀態、資料夾大小、更新時間及順序編號。
- 選擇父系列或單一章節後，將指定範圍圖片連續編號並整合成 `Chapter X-Y`。
- 可選擇在整合成功後清除已整合來源，只保留範圍內最後一個資料夾及新輸出。
- 偵測章節 `result` 資料夾，翻譯圖片涵蓋所有原圖後才能封裝為 Komga 可讀取的 CBZ；只有 `result`、沒有原圖的既有章節仍可匯出。
- 支援自然排序、Unicode 路徑、增量跳過／更新、原子替換及批次錯誤隔離。
- 手動清空 `mask`、`inpainted` 內容；Komga 整批匯出成功後自動清理。
- 大型目錄掃描、漫畫整合、CBZ 匯出與清理皆在背景執行。

## 下載

從 [GitHub Releases](https://github.com/Honguan/Comic-sorting/releases/latest) 下載最新的 Windows x64 EXE。程式不依賴 WinRAR、7-Zip 或外部壓縮工具。

## 使用方式

介面支援繁體中文、English 與日本語。在視窗上方選擇語言會自動儲存，重新啟動後套用至按鈕、狀態、進度及提示訊息；BallonsTranslator 原生視窗的語言由它自己的設定控制。

1. 啟動 `Comic sorting.exe`。
2. 選擇漫畫路徑；可直接選擇包含多個系列的高層級目錄。
3. 在樹狀列表選擇父系列或章節，確認起始與結束編號後執行整合。
4. 翻譯工具完成 `result` 圖片後，按「重新掃描」。
5. 設定 Komga 輸出路徑，匯出選取項目或所有已翻譯項目。

上方漫畫列表支援搜尋與 Ctrl／Shift 多選，搜尋後選取系列只包含目前顯示的章節；重新掃描會保留仍存在的選取項目與展開狀態。整合範圍預設為選取章節的起訖編號，跨系列不可整合；匯出可同時選取多個系列。

Ctrl＋F 可移到搜尋欄，Esc 或「清除搜尋」清空查詢。連續輸入會等待 180 毫秒再更新列表。上下區域間的分隔線可拖曳調整大小，小視窗會優先保留開始／停止與其他操作按鈕。

整合的起訖編號指列表中的順序編號。選取父系列或單一章節時可以調整範圍；Ctrl／Shift 複選多個章節時只整合實際選取項目，範圍欄位會停用。請選擇不重疊的來源，例如複選 `Chapter 1-45` 與 `Chapter 46` 會產生 `Chapter 1-46`；不要把已包含在合併範圍內的 `Chapter 45` 再選入。只選取既有合併輸出時會沿用它，保留翻譯結果。若以原始章節重建同名輸出，確認視窗會提示覆寫其中的翻譯結果；任一來源沒有原圖時，整合會停止並保留來源。

下方分為「主佇列」「Komga 匯出」「設定」三個分頁，漫畫列表持續顯示。BallonsTranslator 路徑與原生設定入口位於「設定」。

輸出結構：

```text
D:\Komga\
└─ Series Name\
   ├─ Chapter 1.cbz
   └─ Chapter 2-10.cbz
```

CBZ 根目錄只包含 `result` 內的 `.png`、`.jpg`、`.jpeg`、`.webp` 圖片，不會重新編碼或壓縮圖片。

## BallonsTranslator 佇列

- 設定安裝路徑、既有 config JSON；Python 留白時使用安裝目錄的 `ballontrans_pylibs_win/python.exe`，其他環境可指定其 Python。
- 新設定的安裝路徑留空，請先瀏覽選擇；既有設定會保留，選擇安裝目錄時會帶入其 `config/config.json`。
- 「開啟原生設定介面」直接啟動 BallonsTranslator，設定模型、OCR、翻譯器及排版後儲存並關閉，再開始佇列。環境、模型及工具均使用該安裝。
- 「編輯設定檔」可直接在 Comic sorting 內編輯所選 config JSON，詳見下方說明。
- 上方列表支援 Ctrl／Shift 多選，選擇「翻譯」「匯出」「清理」後加入佇列，也可逐次加入指定章節路徑。相同路徑與動作不重複加入。
- 雙擊上方章節列可直接將該章節加入主佇列，沿用目前選擇的動作；雙擊系列列仍是展開／收合，空白處不會加入。工作執行期間不可加入。
- 在主佇列選取**單一翻譯項目**，按「翻譯頁數」設定起始／結束頁（包含兩端）；多選、匯出／清理項目與執行期間不可設定。預設「全部頁面」，結束頁留白表示到最後；頁碼從 1 起算，按圖片檔名自然排序，並非檔名中的數字。各項範圍獨立保存；修改範圍後該項回到「等待」。
- 指定範圍使用原生頁面選擇流程，只處理所選頁面，保留範圍外的圖片與翻譯；四階段進度的總頁數改為本次選取頁數。指定頁面完成即可算該項成功；全章 `result` 尚未齊全時略過自動匯出與清理，原因可在工作詳情查看，齊全後才沿用整章 CBZ 匯出。需要支援 `pages_to_process` 的 BallonsTranslator 版本。
- 翻譯工作須至少啟用一個原生處理階段；全部關閉時會提示設定錯誤，避免原生無任務流程停留不退出。
- 主佇列依序處理；可選翻譯成功後匯出 CBZ、成功後清理 `mask`／`inpainted`。任一步驟失敗會跳過該路徑的後續動作，其他路徑繼續。
- 每個翻譯工作及勾選的後續動作成功後，自動開啟 Windows 檔案總管：未匯出時開啟 `result` 資料夾；已匯出時選取完成的 CBZ（包含增量沿用的檔案）。失敗或停止時不會開啟；開啟失敗會提示路徑並記錄日誌，不影響工作完成狀態。
- 「一鍵整合＋主佇列」使用目前選定系列的起訖範圍，將整合輸出加入翻譯佇列並執行主佇列與勾選的後續動作。
- 主佇列顯示工作完成數；BallonsTranslator 的文字偵測、OCR、修補與翻譯各有獨立進度條，同時顯示百分比、已處理頁數／總頁數與預估剩餘時間，例如 `55%｜417/755 頁｜剩餘 33:36`。頁數與 ETA 直接取自原生進度輸出，隨頁面處理更新；尚未取得速度時顯示「估算中」，未啟用的階段顯示「未啟用」，停止／失敗時保留已處理頁數並更新狀態。每個新工作會重設四條進度，匯出進度另外顯示。停止會終止目前翻譯程序，佇列匯出會在下一張圖片檢查取消並保留既有 CBZ，清理則完成當前步驟後停止。
- 工作狀態更新時會儲存，重新開始只執行「等待」項目；已保存的完成工作不會重跑。程式中斷後，上次執行中的項目顯示「已停止」，請先確認結果再「重試選取」。保存失敗會要求停止目前佇列。可上移／下移、重試選取、清除已完成；再次主動加入相同路徑與動作會將該工作重設為等待，不新增重複列。
- 雙擊佇列項目可查看完整路徑與錯誤詳情，包括致命錯誤摘要、翻譯程序最後 20 行輸出與 log 路徑。失敗或停止的前置工作須先重試，才能繼續同路徑的後續工作。翻譯以單一路徑清單啟動，支援含逗號的系列與章節名稱。

## 編輯 BallonsTranslator 設定檔

在「設定」指定 BallonsTranslator 安裝目錄、Python 與既有 config JSON，按「編輯設定檔」。欄位依所選安裝的 [BallonsTranslator 設定定義](https://github.com/dmMaze/BallonsTranslator/blob/dev/ballontranslator/utils/config.py) 及原生模組參數產生，不需啟動模型或連線呼叫 API。

- 左側可搜尋中文名稱或原始欄位名稱；展開物件與清單即可編輯所有已保存欄位、原生預設欄位及自訂模組參數。既有未知欄位會保留。涵蓋自動化流程、偵測／OCR／翻譯／修補器、LLM 配置卡與上下文、字體排版與文字特效、繪圖工具、拼寫檢查、取代規則、輸出格式、套件與鏡像，以及介面等進階設定。
- 布林值使用核取方塊；數字保持數值型別；模型／語言與模組選項使用下拉選單；提示詞支援多行文字；檔案路徑可瀏覽選取。自訂模型名稱可直接輸入，並同步加入該配置卡的模型選項。
- LLM 配置卡、取代規則、文字特效與變形可從原生範本新增；清單可複製、排序、移除，其他物件可新增指定型別的欄位。配置卡 ID 必須唯一，仍被選用的配置卡不能直接刪除而留下無效參照。
- API 金鑰預設遮蔽，留白保留原值，輸入新值取代，勾選清除才會刪除。新的 LLM 金鑰使用 BallonsTranslator 原生可攜式保存格式；既有保存格式保持不變。設定內容與金鑰不寫入應用程式日誌。
- 點選其他欄位會套用編輯中的值；「儲存設定檔」或 Ctrl＋S 才寫入檔案。先完成型別及原生設定檢查，再建立同目錄的 `config.json.<時間>.bak` 備份並原子替換。檔案被其他程式修改時拒絕覆蓋，須重新載入。關閉視窗時可儲存、放棄或取消。
- `finish_code` 由流程開關計算；新版文字特效的舊版相容欄位顯示為唯讀，請改用 `global_fontformat → text_effects` 編輯實際生效的設定。
- 先儲存並關閉設定編輯器，再啟動翻譯。編輯器與從本工具啟動的原生設定介面不可同時使用；既有原生設定入口仍可用。

設定編輯器需要所選 BallonsTranslator 的 Python 能載入其設定與靜態模組定義。安裝或 Python 路徑不正確、設定 JSON 損壞時會顯示錯誤並保留原檔。

## 日誌與失敗判斷

- EXE 同目錄的 `logs/comic-sorting.log` 記錄啟動、掃描、整合、匯出、清理、設定保存失敗與介面例外。可從「設定 → 開啟紀錄資料夾」開啟。
- 每批佇列有獨立識別碼，記錄工作路徑／動作、BallonsTranslator 啟動命令與工作目錄、PID、標準輸出／錯誤輸出、退出碼、重試診斷、結果檢查與最終狀態。
- log 採 UTF-8，每檔最多約 10 MB，保留 3 個輪替備份（`.1`～`.3`）。不記錄設定檔內容，常見金鑰、Authorization、密碼與 access token 會遮蔽；日誌仍包含漫畫路徑與翻譯器輸出，分享前請檢查內容。
- BallonsTranslator 會在 LLM 回應格式錯誤、準備內建重試時先記一筆 `ERROR`。這個已知重試診斷不再直接造成整批失敗；重試耗盡、模型輸出上限、真正 traceback、流程中止、非零退出碼或缺少完成標記，仍判為失敗，且不執行後續匯出／清理。
- `exit=0` 只代表程序正常退出，不代表每頁成功。例如 `LLM output limit reached` 會中止翻譯流程，即使程序最後仍顯示完成所有目錄，也必須先處理對應模型設定或回應問題。

## 清理注意事項

「整合後清除來源（保留最後一個）」預設關閉；啟用後會記錄在可攜式設定 JSON，後續啟動保持開啟。刪除只會在新整合輸出成功後執行，且無法復原。

「清理所有 mask / inpainted」會清空目前漫畫路徑下所有同名資料夾的內容，但保留資料夾本身。手動清理前會要求確認，操作無法復原。

Komga 匯出會在狀態檔保存成功後，自動清理實際匯出成功章節的工作資料；未選取或匯出失敗的章節不會被清理。

## 路徑綁定與增量狀態

- 可攜式設定：EXE 同目錄的 `comic-sorting.settings.json`
- Komga 增量狀態：`<Komga 路徑>\.comic-sorting-state.json`

首次啟動時漫畫與 Komga 路徑皆為空白，必須手動設定。設定後會自動保存並在後續啟動時讀取；重新瀏覽即可改綁其他路徑。移動 EXE 時請連同設定檔一起移動。

手動輸入有效漫畫路徑後按 Enter／重新掃描也會保存；兩個匯出選項會在重啟後保留。掃描不進入 `result`、`mask`、`inpainted` 與整合暫存／備份目錄尋找章節，也不追蹤目錄連結；資料夾大小不計入連結指向的外部內容。

增量狀態依圖片名稱、大小及修改時間判斷來源是否變更，並檢查 CBZ 大小與修改時間。CBZ 被改動時重新建立；舊版狀態首次沿用 CBZ 前會驗證內容。不同來源的同名系列／章節若會覆蓋已記錄的輸出，會明確報錯，請改用不同的 Komga 路徑或系列名稱。

改善項目、架構取捨與驗證結果見 [改善計畫](IMPROVEMENT_PLAN.md)。

## 開發與建置

- `comic_core.py`：圖片、CBZ、JSON 與清理等共用檔案操作。
- `queue_worker.py`：穩定的工作／狀態代碼、BallonsTranslator 子程序及佇列執行；以事件回傳結果，不操作視窗。
- `translation_queue.py`：佇列介面、排序、重試及狀態保存。
- `bt_settings.py`：完整設定欄位編輯、型別檢查、備份及存檔衝突檢查；`bt_config_bridge.py` 使用所選翻譯器環境讀取定義、檢查設定與保存金鑰。
- `Comic sorting.py`：漫畫列表、整合與主視窗協調；`ui_language.py` 管理三語文字。

需求：Python 3.10、PyInstaller 6.14.1。

```powershell
py -3.10 -B -m unittest discover -s tests -v
py -3.10 -m PyInstaller --clean --noconfirm "Comic sorting.spec"
```

建置輸出位於 `dist\Comic sorting.exe`。推送 `v*` 標籤時，GitHub Actions 會執行測試、建置並建立 Release。
